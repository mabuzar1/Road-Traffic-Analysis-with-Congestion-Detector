# Road-Traffic-Analysis-with-Congestion-Detector
This project is an interactive road traffic analysis system that allows the user to simulate real-time traffic conditions on multiple routes. The program lets the user add vehicles to different roads by entering the number of vehicles and their average speed, making the system feel realistic and user-controlled. Each road uses a linked list to store vehicle speeds, which helps in calculating average speed and detecting congestion accurately. Based on vehicle count and speed ratio, the system displays clear congestion levels such as free flow, light traffic, moderate congestion, or heavy congestion. It also shows a complete summary of all roads, including congestion score, speed limits, and current traffic conditions in an easy-to-understand format. Using travel time calculations and Dijkstra’s algorithm, the program finds the shortest and fastest route from Home to University.
Overall, this project combines data structures and algorithms with a menu-driven interface to help users make smart and safe route decisions.
